Exercise Title Single Page Academic Dashboard (EduDashboard) using React 19
Live Hosted URL https://jinto-joseph.github.io/WEB_TECH_LAB/Exp_08/react-ui-lab/index.html

Aim:

To design and develop a single page component-based academic overview dashboard (EduDashboard) utilizing React 19, demonstrating modular components, props, useState hooks, dynamic list management, and light/dark theme switching.

Key Features & Concepts Demonstrated:

  • Component Hierarchy: Modular separation of concerns with Navbar, StatCard, and App parent component.
  • State Management (useState): Controlled input state for adding tasks, toggling completion, dynamic filtering, and dark/light mode toggle.
  • Props Communication: Passing custom titles, values, status indicators, and event callbacks (onToggleTheme) through props.
  • Dynamic Rendering: Array mapping for courses and interactive task list with conditional styling.
  • Responsive CSS3 Design: Mobile, tablet, and desktop flexbox/grid adaptation with synchronized dark theme.
