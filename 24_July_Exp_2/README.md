## 📌 Objective / Aim

To build a website that conforms to HTML5 standards incorporating document structure, text formatting, images, anchors, tables, form controls (`<form>`, `<input>`, `<select>`, `<textarea>`, `<fieldset>`, `<legend>`, `<progress>`), and HTML5 media elements (`<audio>`, `<video>`, `<embed>`, `<iframe>`).
