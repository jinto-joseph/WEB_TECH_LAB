## 📌 Objective / Aim

To develop a webpage using HTML5 tags and apply styles to the webpage using CSS3 properties and layouts like Normal flow, Multicolumn layout, Flexbox/Grid, and Responsive Media Queries (`@media`).

---

## 🏷️ CSS3 Properties & Layout Concepts Covered

```
┌───────────────────┬────────────────────────────────────────────────────────┐
│ Category          │ CSS3 Properties Implemented                            │
├───────────────────┼────────────────────────────────────────────────────────┤
│ Margins           │ margin, margin-top, margin-bottom, margin-left/right   │
│ Formatting Text   │ color, letter-spacing, text-align, text-decoration,   │
│                   │ text-shadow                                            │
│ Font Styling      │ font-family, font-style, font-weight, font-size        │
│ Backgrounds       │ background-color, background-image, background-repeat  │
│ Padding           │ padding, padding-top, padding-bottom, padding-left     │
│ Link States       │ a:link, a:visited, a:hover, a:active                   │
│ Display & Flow    │ display: inline, display: block, display: flex, grid   │
│ Multicolumn Grid  │ 4-Column Tech Cards, 3-Column Family Cards             │
│ Responsiveness    │ @media (max-width: 768px), @media (max-width: 480px)   │
└───────────────────┴────────────────────────────────────────────────────────┘
```
