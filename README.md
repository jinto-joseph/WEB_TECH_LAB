## ⚡ How to Add Next Experiments (Simple Workflow)

When you do a new experiment (e.g. Exp 2):
1. Create a folder in this repo (e.g. `Exp_2`).
2. Add your HTML files inside `Exp_2`.
3. Push to GitHub:
   ```bash
   git add .
   git commit -m "Added Experiment 2"
   git push origin master
   ```
4. GitHub Pages will automatically host your new experiment live at:
   `https://jinto-joseph.github.io/WEB_TECH_LAB/Exp_2/`
