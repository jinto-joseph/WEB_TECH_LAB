Read & Query Operations
11. Display All Documentsfind
collegeDB> db.students.find()
12. Find One DocumentfindOne
db.students.findOne({ rollno: 103 })
13. Search Using Condition
db.students.find({ department: "CSE" })

Object inside find() = query filter.

📊 14. Comparison Operators

OPERATORS
$gtGreater than
$gteGreater than or equal
$ltLess than
$lteLess than or equal
$eqEqual
$neNot equal
$inMatches array values
$ninDoes not match array
marks > 80
db.students.find({ marks: { $gt: 80 } })
marks >= 80
db.students.find({ marks: { $gte: 80 } })
marks < 80
db.students.find({ marks: { $lt: 80 } })
marks ≠ 85
db.students.find({ marks: { $ne: 85 } })
Logical Queries, Projection & Sorting
15. AND Condition (implicit)
db.students.find({
    department: "CSE",
    marks: { $gt: 75 }
})

Multiple fields in same filter = implicit AND.

16. OR Condition
db.students.find({
    $or: [
        { department: "CSE" },
        { department: "ECE" }
    ]
})
17. Projection
db.students.find(
    {},
    { name: 1, marks: 1, _id: 0 }
)

1 includes · 0 excludes field.

18. Sort Documents
// Ascending
db.students.find().sort({ marks: 1 })
// Descending
db.students.find().sort({ marks: -1 })
19. Limit Results
db.students.find()
    .sort({ marks: -1 })
    .limit(3)

Top 3 scorers.

20. Count Documents
// All
db.students.countDocuments({})
// CSE only
db.students.countDocuments(
    { department: "CSE" }
)
Update Operations
21. Update One DocumentupdateOne
db.students.updateOne(
    { rollno: 101 },
    { $set: { marks: 90 } }
)
22. Update Multiple DocumentsupdateMany
db.students.updateMany(
    { department: "CSE" },
    { $set: { status: "Active" } }
)

Adds status field for all CSE students.

23. Increment Numeric Value
db.students.updateOne(
    { rollno: 103 },
    { $inc: { marks: 5 } }
)

$inc increases the value by the given amount.

Delete & Distinct Operations
24. Delete One DocumentdeleteOne
db.students.deleteOne({ rollno: 105 })
25. Delete Multiple DocumentsdeleteMany
db.students.deleteMany(
    { marks: { $lt: 70 } }
)

⚠️ Run only after all queries that need this data.

26. Distinct Values
db.students.distinct("department")
// [ "CSE", "ECE", "EEE" ]
Aggregation Pipeline
27. Dept-wise Average Marks$avg
db.students.aggregate([
    {
        $group: {
            _id: "$department",
            averageMarks: { $avg: "$marks" }
        }
    }
])
28. Maximum Marks$max
db.students.aggregate([
    {
        $group: {
            _id: null,
            maximumMarks: { $max: "$marks" }
        }
    }
])

Also: $min · $avg · $sum

29. Dept-wise Student Count$sum
db.students.aggregate([
    {
        $group: {
            _id: "$department",
            totalStudents: { $sum: 1 }
        }
    }
])
Indexing, Utility & Cleanup
30. Create & View Index
// Create index
db.students.createIndex({ rollno: 1 })

db.students.getIndexes()

// Deletes collection + all documents
db.students.drop()

// Confirm current DB first
db

db.dropDatabase()
