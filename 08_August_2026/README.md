## 📌 Objective / Aim

To design and develop an interactive webpage that demonstrates advanced CSS3 image styling capabilities including custom CSS border frames (`border-image`), single and multi-layered background images, styled table lists with hover-triggered image opacity transitions, and responsive user authentication card forms over a textured background container.

---

## 🏷️ CSS3 Features & Concepts Covered

```
┌───────────────────┬────────────────────────────────────────────────────────┐
│ Category          │ CSS3 Properties & Techniques Implemented               │
├───────────────────┼────────────────────────────────────────────────────────┤
│ Border Images     │ border-image: url(...) 40 stretch                      │
│ Multi Backgrounds │ background-image with 4 layered images (sun, flower,  │
│                   │ apple, header-bg), background-position, background-size│
│ Background Covers │ background: url(...) center/cover for desk section     │
│ Table Styling     │ nth-child(odd/even) alternating row colors             │
│ Hover Effects     │ tr:hover img opacity transition (0.3 to 1.0)           │
│ Card Forms        │ Form inputs, labels, flexbox centering & sign-in/up   │
└───────────────────┴────────────────────────────────────────────────────────┘
```
