## 📌 Objective / Aim

To understand and implement core HTML5 building blocks including document structure, headings (`<h1>`–`<h6>`), line breaks (`<br>`), text formatting, semantic tags (`<cite>`, `<blockquote>`, `<abbr>`), image embedding (`<img>`), and pure inline CSS styling (`style="..."`) to construct a real-world corporate portal scenario (**Infosys Employee Training Portal**).
