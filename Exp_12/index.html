Experiment No. 12 — Full Stack Web Application

Student Management System using ReactJS, NodeJS, ExpressJS and MongoDB

Open React Frontend Back to Lab Portal

Aim

To design and develop a full-stack student management application with a React frontend, an Express REST API, and MongoDB storage, and to perform Create, Read, Update and Delete operations.

Application Architecture

ReactJSStudent form and records table
AxiosHTTP communication
ExpressJSREST API endpoints
MongoDBPersistent student documents

CRUD API

  • POST /students creates a student.
  • GET /students lists all students.
  • PUT /students/:id updates a student.
  • DELETE /students/:id removes a student.

The API and MongoDB connection run locally. Follow the setup instructions in the project README.
